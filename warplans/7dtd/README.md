# 7 Days to Die

The PEON war plan used to deploy a 7 Days to Die dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/7dtd/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Update `serverconfig.xml` in the data volume for deeper tuning.
