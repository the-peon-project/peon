# Terraria

The PEON war plan used to deploy a Terraria dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/terraria/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- World and gameplay config should be handled through Terraria server config files.
