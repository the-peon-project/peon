# Don't Starve Together

The PEON war plan used to deploy a Don't Starve Together dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/dst/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Configure cluster and shard files in the persistent user volume.
