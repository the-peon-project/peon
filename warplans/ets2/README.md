# Euro Truck Simulator 2

The PEON war plan used to deploy an Euro Truck Simulator 2 dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/ets2/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Multiplayer server behavior is configured through ETS2 server config files.
