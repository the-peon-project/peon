# Unturned

The PEON war plan used to deploy an Unturned dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/unturned/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Server identity and map settings are handled in the Unturned server files.
