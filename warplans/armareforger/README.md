# Arma Reforger

The PEON war plan used to deploy an Arma Reforger dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/armareforger/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Tune mission, mods, and authentication through Arma Reforger config files.
