# DayZ

The PEON war plan used to deploy a DayZ dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/dayz/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Place DayZ server config files in the mounted server data path as needed.
