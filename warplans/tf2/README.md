# Team Fortress 2

The PEON war plan used to deploy a Team Fortress 2 dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/tf2/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Override map/player/token values through environment settings in PEON.
