# Project Zomboid

The PEON war plan used to deploy a Project Zomboid dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/projectzomboid/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Server save data persists in the mapped `user` volume.
