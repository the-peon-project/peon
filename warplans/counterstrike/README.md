# Counter-Strike

The PEON war plan used to deploy a classic Counter-Strike dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/counterstrike/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Map and player values are controlled through the plan environment settings.
