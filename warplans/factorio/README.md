# Factorio

The PEON war plan used to deploy a Factorio dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/factorio/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Place `server-settings.json` in the config volume for custom game behavior.
