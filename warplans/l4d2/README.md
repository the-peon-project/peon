# Left 4 Dead 2

The PEON war plan used to deploy a Left 4 Dead 2 dedicated server.

## Documentation

- PEON docs: http://docs.warcamp.org/games/
- Recipe path: `peon-warplans/l4d2/`

## Notes

- This recipe uses the `umlatt/steamcmd` PEON runtime mode.
- Default campaign map can be changed with `MAP`.
