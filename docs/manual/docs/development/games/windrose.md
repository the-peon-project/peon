# Windrose

The PEON war plan that PEON uses to deploy your game server.

## Runtime Notes

- Dedicated server SteamCMD app id: `4129620`
- Server launch binary: `WindroseServer.exe`
- Dedicated server mode uses `steamcmd-proton` to keep PEON runtime state files populated for API surfaces
- Default direct connection port: `7777` (`tcp/udp`)
