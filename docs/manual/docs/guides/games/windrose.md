# Windrose

## Before you start

### World Saves

Your world saves are stored in `./user` when using the PEON recipe.

All server files can be found in the local PEON server path:

`./peon/servers/[game_uid]/[server_name]/`

## Stand-alone mode

[Guide on GitHub](https://github.com/the-peon-project/peon-warplans/tree/main/windrose#guide)

> Or... just use PEON. it should do all the heavy lifting for you.

## Notes

- Windrose dedicated server installs through SteamCMD app id `4129620`
- This PEON recipe runs the server with the `umlatt/steamcmd-proton` image so PEON runtime metadata (`state`, `ip`, config files) remains visible in API responses
- The default direct-connect port is `7777` (`tcp/udp`)
